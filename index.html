You are taking timed codebreaking contracts. Beat the clock for a payout; after the deadline, the puzzle can still be solved for practice but pays $0.

Caesar: slide the alphabet until common words appear. A single shift decodes every letter.

Vigenere: A Vigenere cipher hides a message by shifting each letter by a different amount based on a repeating keyword. It is like using several Caesar ciphers in a pattern instead of just one.

Substitution: A substitution cipher replaces each plaintext letter with a different cipher letter. The same encrypted letter always stands for the same plaintext letter, so repeated letters, common words, and given letter values are the best way in.

Atbash: reverse the alphabet. A becomes Z, B becomes Y, and the pattern continues inward.

Rail Fence: arrange letters in zigzag rails, then read across or rebuild the rails to recover the message.
